# Atelier de l'atome · Atom Workshop · ورشة الذرة

An interactive web app for teaching atoms and the first three periods of the periodic table (Z = 1 to 18).

- **Tableau**: the simplified 8-column table. Click an element to see its shell model (K, L, M), Z, A, protons, neutrons, electrons, electron configuration and usual ion.
- **Construire**: build an atom or ion by dragging protons, neutrons and electrons onto it, with live calculations and challenges.
- **Règles**: the course rules (in French) for the charge and mass of the nucleus, electrons, atom and ion, each with a two-way calculator.
- **Quiz**: 10 random questions, each with an explanation.

The interface is available in French, English and Arabic (right-to-left). The rules always stay in French.

Plain HTML, CSS and JavaScript, with no build step: open `index.html` or serve the folder.
